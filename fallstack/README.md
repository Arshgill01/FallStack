## Fallstack Devvit Web App

Fallstack is a Devvit Web Phaser game for Reddit interactive posts.

Stack:

- [Devvit Web](https://developers.reddit.com/docs/capabilities/devvit-web/devvit_web_overview): Reddit app hosting, interactive posts, server capabilities.
- [Phaser](https://phaser.io/): 2D game rendering, physics-feeling movement, camera, input, and effects.
- [Vite](https://vite.dev/): Client/server build pipeline.
- [Hono](https://hono.dev/): Server endpoint routing.
- [TypeScript](https://www.typescriptlang.org/): Shared types and pure game logic.

## Commands

- `npm run dev`: Uploads a playtest build and watches for changes.
- `npm run build`: Builds the client and server projects.
- `npm run deploy`: Type-checks, lints, and uploads a new app version.
- `npm run launch`: Uploads and publishes the app for review.
- `npm run login`: Logs the Devvit CLI into Reddit.
- `npm run type-check`: Runs TypeScript project checks.
- `npm run lint`: Runs ESLint.
- `npm test`: Runs type-checking and compiled shared/client tests.

Current playtest subreddit: `r/fallstack_dev`.
