# Scenario versus Layer bake-off

## Fixed trial brief

Generate the same three deliverables from the selected art bible:

1. One opening-zone platform family: top, middle, edge, cracked, and stabilised variants.
2. One community artifact family: base, upgraded, cursed, and stabilised states with unmistakable collision semantics.
3. One player: idle, charge-low, charge-high, leap, impact, and fall concepts.

Require transparent backgrounds, consistent orthographic side view, no text, no generic pixel-art treatment, and enough padding for atlas normalization. Preserve prompts, seeds/settings, licenses, generation time, and raw outputs.

## Evaluation

Score both providers against the art-director scorecard plus:

- cross-state silhouette and material consistency
- controllability from the same references
- clean transparency and edge quality
- reproducibility and API ergonomics
- commercial rights and provenance clarity
- cleanup time to Phaser-ready assets
- cost per accepted asset, not cost per generation

Use the same reviewer and normalization steps. Reject attractive single images that cannot form a coherent family. Select one provider only after a small Phaser import proof; if neither clears the quality bar, select neither and revise the brief.

## Authorization boundary

Account creation, free trials, and test generations are within the approved workflow. Stop before starting a paid subscription or bulk generation and present measured cost and score differences for explicit approval.
